# milan

Dieses Projekt wurde mit [Angular CLI](https://github.com/angular/angular-cli) erstellt.

## kicad-python

```bash
npm install -g @angular/cli
ng new milan
cd milan
npm install
```

## gbtools

```bash
ng serve
```

Öffnen Sie `http://localhost:4200/` im Browser. Die Anwendung lädt automatisch neu bei Änderungen.

## pflag

```bash
ng generate component components/booking
ng generate service services/hotel
ng generate module modules/shared
```

## catpix

```bash
ng build
```

Build-Artefakte werden im `dist/`-Verzeichnis gespeichert.

## browserify-demo

```bash
ng test
```

Unit-Tests mit [Karma](https://karma-runner.github.io).

```bash
ng e2e
```

End-to-End-Tests mit Cypress.

## InflectorKit

```bash
ng build --configuration production
```

Optimierter Production-Build mit AOT-Kompilierung und Tree-Shaking.
